Ini adalah catatan berdasarkan temuan saya:

* Di app UPZ Al-Fajar (Manajemen Zakat Fitrah), ada group namanya data master, yaitu memuat tentang data muzakki dan mustahik. saya ingin setiap penambahan muzakki dan mustahik ini harus disimpan di app Data Master (Manajemen Data Induk).
  * Nah, nanti di data master, karena ada tab warga, itu diubah aja jadi terminologi Kontak, di sana memuat informasi pribadi.
  * Masih boleh nambah data muzakki atau mustahik on the fly, tapi orang tersebut harus mengacu ke data master (kontak).
  * Jadi perihal orang, atau informasi pribadi, wajib ada di data master kontak.
  * Termasuk admin atau petugas, atau user biasa juga harus ada dulu di kontak.
  * Jadi nanti di halaman master data muzakki (ganti nama jangan ada istilah master, ganti jadi daftar muzakki saja), pasti memuat orang dari kontak, di tabel ada nama, alamat, nomor telepon, riwayat transaksi
    * Nanti dari spesifik muzakki, bisa dilihat list riwayat transaksi.
  * Begitu juga mustahik, harus refer ke data master kontak, masih boleh buat mustahik on the fly, tapi informasi orang harus mengacu pada database master kontak.
* Ini masih fokus dulu di aplikasi UPZ Al-Fajar (Manajemen Zakat Fitrah), nanti akan coba masuk ke aplikasi Qurban, dan pinjaman jamaah.
